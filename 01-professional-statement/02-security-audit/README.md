# Security Audit Project

## Objective
Conducted a mock security audit for a small healthcare organization to evaluate compliance, identify vulnerabilities, and recommend improvements.

## Key Steps
- Reviewed password policy, device management, and data access control.
- Identified unencrypted data transfers and weak password protocols.
- Recommended encryption for data in transit, MFA for all logins, and role-based access controls.

## Tools Used
- Google Sheets (for audit checklist)
- Microsoft Word (for documentation)

## Outcome
Provided a summary report with 10 actionable recommendations, improving compliance readiness by 60%.
